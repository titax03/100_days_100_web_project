# WanderLust
**Find your next escape.**

WanderLust is a next-generation travel property platform designed to make finding your dream stay effortless. We bring the world's best escapes right to your screen with a lightning-fast, beautifully designed interface. 

## Why WanderLust?
* **Instant Discovery:** Real-time search filtering lets you find exactly what you want, the moment you type it.
* **Adaptive Experience:** Seamless Dark and Light mode integration that remembers your viewing preferences.
* **Modern Aesthetics:** A premium glassmorphism UI built for visual clarity and smooth interactions.
* **Flawless Layouts:** Responsive grid architecture that looks perfect on mobile, tablet, and desktop.

## Under the Hood
* HTML5
* CSS3 (Custom Variables, Flexbox, Grid)
* Vanilla JavaScript (DOM Manipulation, LocalStorage)

## Quick Start
1. Clone the repository to your local machine.
2. Navigate into the `WanderLust` directory.
3. Open `index.html` using your browser or a tool like VS Code Live Server.

We are building more than just a listing site; we are building the future of digital travel discovery.
